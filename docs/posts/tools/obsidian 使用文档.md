
# obsidian 使用文档


### obsidian 常见配置

#### 三方市场插件安装
1. 打开设置，或使用快捷键 command + ,
2. 选择第三方插件，
3. 社区插件市场，点击浏览
4. 在弹窗中搜索需要安装的插件名称
5. 选中插件，点击安装
6. 安装完成后点击启用
