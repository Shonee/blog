# GitHub 仓库部署 VitePress 博客

## 项目地址

- 参考项目：<https://github.com/Shonee/VitePressDemo>
- 访问地址：<https://shonee.github.io/VitePressDemo/>

## 部署说明

1. 在仓库中维护 `docs/` 文档目录。
2. 使用 GitHub Actions 自动构建并部署到 GitHub Pages。
3. 推送更新后即可在页面中查看最新内容。
