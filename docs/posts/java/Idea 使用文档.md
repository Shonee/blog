


### MAC上设置IDEA如何一个窗口打开多个项目，多个tab
如果你打开了多个项目、每次切换都要半天，想让项目都汇聚到top栏
1. 首先保证打开了多个窗口，否则该功能按钮直灰不可用
2. 点击 Window - Merge All Project Windows 即可

### 项目内打开很多个文件如何不是一行展示
往往没设置的时候，IDEA会自动只有一行展示，多的需要左右滑动查看，再多的就被挤掉了
设置tab多行展示、就算打开再多的文件也都可以展示了
1. 打开设置
2. 取消勾选：show tabs in one row


### IntelliJ IDEA自带的文本差异对比器（对比和剪贴板）
#### 对比文本
1. 将需要对比的文本内容选中并复制到剪贴板（Ctrl+C）上
2. 在idea中选择需要对比的另外一处文本，右击Compare with Clipboard即可显示差异。
3. 不选择指定文本是默认当前文件和剪贴板内容进行对比

#### 对比文件
1. 打开要比对的文件，右键选择Compare With
2. 选择本地需要带比对的文件，双击即可进行对比
